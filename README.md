# Easy Pattern Studio demo

Free, password-free browser demo by Vanya Illustrations with 13 watermarked Halloween motifs. Editing and image exports run on the visitor’s device.

## Build

Run `npm install` and `npm run build`. The output in `dist` is published from `docs` by GitHub Pages.
